# 尚未接入／当前边界

这是现状清单，不是授权AI通过shell、源码或数据库补做的任务。缺少接口就报告不支持，不绕过后端。

| 功能 | 当前状态／可用替代 |
|---|---|
| 账号导出 | 没有Linux HTTP接口；可导入已有桌面导出文件，不反向读数据库提取Key |
| 修改RunningHub现有Key | 无接口；不能擅自删除重加 |
| 修改账号标签 | 无专用接口 |
| Gemini一键检测全部 | 无专用接口；用户要求时可逐个指定Key检测；无id的test仅测试一次轮询 |
| Gemini并发数设置 | 当前固定最多4请求，无设置接口 |
| 调度器启动／停止 | 无HTTP操作接口；health只读状态，服务运维由管理员执行 |
| 全局命名规则与下载目录设置 | 无设置接口；表单有taskName，旧接口允许每任务namingRule；不擅改全局数据目录 |
| 工作流导出 | 无标准便携包导出接口；GET详情不是导出包 |
| 个人工作流高层表单 | 尚未接到workspace；已有明确映射可用原始兼容接口，不能自行猜测 |
| 模块切换并保留未提交草稿 | 无完整接口；workspace批次保存的是可提交表单，不是桌面所有未填写完的草稿 |
| 单素材交换／逐项批次操作／批次排序 | 无独立操作接口；用户要求时提交PATCH完整tasks列表，图片顺序由images数组指定 |
| 保存空白草稿、清空必填内容后保留草稿 | workspace会校验，当前不能保存不完整任务；删除批次与保存空白草稿不同 |
| 再次生成恢复原草稿 | 无专用接口；不能自动猜原始词/优化开关，新生成必须用户明确指定 |
| 桌面完整任务预览视图 | 没有UI；已有GET任务原始数据及结果文件接口 |
| 复制到系统剪贴板 | 无接口；需要时返回文字字段或保存文件即可 |
| 删除任务同时删本地文件 | 无选项；DELETE任务只删记录，不擅自清理磁盘 |
| TTS一键发送Inf/H3 | 无独立按钮接口；完成file可直接填入目标表单audio，只有用户要求时创建目标任务 |
| 双人TTS、空间声场、自动文本优化 | 未接入；不能通过style承诺这些能力 |
| Skill删除 | 无接口；可切回builtin |
| 自动安装更新 | 无HTTP接口；检查脚本只通知，管理员按安装流程升级 |
| 代理设置 | 按要求无云端代理UI/接口；平台网络环境由管理员维护 |
| 白模预演 | 已排除，不提供接口 |
| 闭源程序与系统权限隔离 | 尚未完成；当前分发仍含源码，文档操作限制不等于技术隔离 |

已接入功能的方法与参数以API_REFERENCE.md为准。未知需求先简短报告缺项，不自行实现新功能，不改用户规则。
